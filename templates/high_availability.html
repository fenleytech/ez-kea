HA Listener URL: where that server's HA hook listens for its partner (heartbeats and lease updates), as http://<IP>:<port>/ (8001 is conventional). Use an IP address, not a hostname, and a port none of the server's HTTP control sockets use. No Kea Control Agent is needed.
Control API URL: where EZ-KEA reaches that peer's own Kea control API to push this server's config to it (8000 is conventional). Leave it blank for this server, or for a peer you will configure by hand. Allow both ports between the servers in any firewall.

Configures Kea's libdhcp_ha.so hook so two servers share lease state and fail over automatically. EZ-KEA also loads libdhcp_lease_cmds.so (HA needs it to sync leases) and turns on the HA hook's own HTTP listener. Both servers must receive every client request: list both in your routers' DHCP relay (helper) addresses, or put both on the clients' segment. In load-balancing mode EZ-KEA splits every pool in half between the two servers. Edit one server here; Apply Changes pushes its config to every peer with a Control API URL.
