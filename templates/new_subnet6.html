Standard Address Pool (IA_NA)

Hands out individual IPv6 addresses to end hosts (PCs, phones, servers) — the IPv6 equivalent of a normal DHCPv4 pool. Use this for regular clients; use Prefix Delegation below for routers/CPE that need their own downstream block.

Prefix Delegation (PD) configuration

Prefix Delegation allows routers on this network to automatically request entire blocks of IPv6 addresses from your server to pass on to downstream devices. If you are just serving standard endpoints (PCs, phones), leave this blank.
